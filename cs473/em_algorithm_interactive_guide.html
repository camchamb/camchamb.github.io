The EM Algorithm, from Intuition to Math

An interactive guide to Expectation–Maximization (EM), with three levels of explanation and a small Gaussian-mixture demo you can step through.

The one-sentence idea: EM helps estimate model parameters when some information is hidden or missing. It alternates between guessing the hidden information using current parameters and updating the parameters using those guesses.

Level 1: Imagine sorting mystery marbles

You have a pile of marbles from two machines. One machine usually makes small marbles; the other usually makes large ones. But the labels fell off, so you do not know which machine made each marble.

EM is a repeated two-step strategy:
1. Make a best-available guess about which machine made each marble.
2. Use those guesses to improve your description of each machine.
Repeat until the guesses and descriptions stop changing much.
Expectation step (E-step)

“Given what I currently believe about the machines, how likely is each marble to have come from each one?”

Maximization step (M-step)

“Given those likely assignments, what machine sizes and proportions fit the marbles best?”

Why not just assign each marble to one machine?

Because a marble in the middle could plausibly come from either machine. EM can use soft assignments: for example, 70% machine A and 30% machine B, rather than making an all-or-nothing guess.

Level 2: The algorithm as a feedback loop

Suppose the data really came from two overlapping groups, but the group labels are hidden. We want to estimate each group's center, spread, and how common it is.

1 — Start

Choose initial guesses for the group centers, spreads, and mixture weights. Initial guesses matter; poor starts can lead to a poor solution.

2 — E-step

For every point, calculate its responsibility: the probability that each component generated it, given the current parameters.

3 — M-step

Re-estimate the parameters, treating responsibilities as fractional membership weights.

4 — Repeat

Recalculate responsibilities with the new parameters, then update again. Stop when changes are small or you hit an iteration limit.

What the E-step is really asking

If a point lies near group A's center and far from group B's center, it receives a high responsibility for A. The probability also depends on each group's spread and how common that group is.

What the M-step is really asking

A group's new center becomes a weighted average: points with higher responsibility for that group count more. Its spread and mixture weight are updated from the same weighted memberships.

Important: E and M are not two different models. They are alternating calculations that improve the same model's fit. With the standard exact EM updates, the observed-data log-likelihood does not decrease from one iteration to the next, although EM can converge to a local optimum rather than the global best solution.

Level 3: College-level formulation

Let observed data be \(X\), latent variables be \(Z\), and parameters be \(\theta\). We want to maximize the observed-data log-likelihood

ℓ(θ) = log p(X | θ) = log ∑Z p(X, Z | θ)

(For continuous latent variables, replace the sum with an integral.) The log of a sum often makes direct optimization difficult. EM alternates between a posterior distribution over latent variables and a parameter update.

E-step: compute the posterior over latent variables

q(Z) ← p(Z | X, θold)

Equivalently, form the auxiliary function

Q(θ, θold) = EZ | X, θold[ log p(X, Z | θ) ]

This is the expected complete-data log-likelihood, where the expectation uses the current parameter estimate.

M-step: maximize the expected complete-data log-likelihood

θnew ← arg maxθ Q(θ, θold)

Then repeat. Under the usual EM conditions, this update does not decrease the observed-data log-likelihood. The sequence typically converges to a stationary point, not necessarily the global maximum. Some models use a generalized EM step that merely increases Q rather than maximizing it exactly.

Example: Gaussian mixture model (GMM)

For point \(x_i\) and component \(k\), responsibility \(r_{ik}\) is the posterior probability that component \(k\) generated the point:

rik = πk 𝒩(xi | μk, σk²) / ∑j πj 𝒩(xi | μj, σj²)

Let \(N_k = \sum_i r_{ik}\). In one dimension, the M-step updates are:

μk = (∑i rikxi) / Nk
σk² = (∑i rik(xi − μk)²) / Nk
πk = Nk / n

Notice the weighted averages: the hidden component labels are replaced by probabilities. This is the core trick that makes the updates possible.
