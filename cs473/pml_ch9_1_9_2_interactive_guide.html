What does “Gaussian” mean?

A Gaussian (normal) distribution is a bell-shaped curve. Examples near the mean are more typical; examples farther away are less typical. In multiple dimensions, covariance describes spread and relationships between features.

LDA versus QDA

  • LDA: all classes share the same covariance (spread/shape). Boundaries are linear: lines in 2D, planes in 3D.
  • QDA: each class has its own covariance. Boundaries can curve, giving more flexibility but requiring more parameters.

Level 2: From distributions to a decision boundary

Gaussian discriminant analysis is a generative approach: it models the distribution of features within each class, along with each class’s prior probability.

p(y = k | x) ∝ p(x | y = k) p(y = k)

Likelihood \(p(x\mid y=k)\) says how well class \(k\) explains the features. Prior \(p(y=k)\) says how common the class is before seeing the features. Bayes’ rule combines them into a posterior class probability.

Why covariance changes the boundary

LDA: shared covariance

When Gaussian classes share covariance, quadratic terms in \(x\) cancel when comparing classes. The discriminant score is linear in \(x\).

QDA: class-specific covariance

When covariance differs, the quadratic terms generally do not cancel. The boundary can curve.

Model fitting

With labeled training data, estimate class priors from class frequencies, class means from feature averages, and covariance from within-class variation. LDA pools information to estimate one shared covariance; QDA estimates a separate covariance for each class.

Nearest-centroid classifier

Predict the class whose mean (centroid) is closest to the new point. Ordinary Euclidean nearest-centroid classification ignores class-specific covariance and priors unless modified. It is simple, but not identical to general Gaussian discriminant analysis.

Remember: The decision rule comes from estimated probability distributions and Bayes’ rule—not from drawing a boundary by eye.

Level 3: College-level formulation

Let \(x\in\mathbb R^D\) be the feature vector and \(y\in\{1,\ldots,K\}\) the class label. Gaussian discriminant analysis models:

p(x | y=k) = 𝒩(x | μk, Σk),   p(y=k)=πk

Bayes’ rule gives the posterior:

p(y=k | x) = [πk 𝒩(x | μk, Σk)] / [∑j=1K πj 𝒩(x | μj, Σj)]

The maximum a posteriori (MAP) classifier predicts \(\hat y=\arg\max_k p(y=k\mid x)\), equivalently maximizing \(\log p(x\mid y=k)+\log\pi_k\).

Discriminant score

δk(x) = −½ log |Σk| − ½(x−μk)ᵀΣk⁻¹(x−μk) + log πk

Terms shared across classes, such as \(-\frac D2\log(2\pi)\), can be dropped when choosing the maximum score.

LDA
Σk = Σ for every k

Expanding the quadratic form, the \(x^TΣ^{-1}x\) term is shared by all classes and cancels. The remaining score is linear:

δk(x)=xᵀΣ⁻¹μk − ½μkᵀΣ⁻¹μk + log πk
QDA
Σk may vary by class

The quadratic term depends on class \(k\), so it generally cannot be removed. The boundary is quadratic in \(x\).

Maximum-likelihood parameter estimates

Let \(N_k\) be the number of training examples in class \(k\), and \(N\) the total.

π̂k = Nk/N
μ̂k = (1/Nk) ∑i:yᵢ=k xᵢ

QDA estimates covariance within each class:

Σ̂k = (1/Nk) ∑i:yᵢ=k (xᵢ−μ̂k)(xᵢ−μ̂k)ᵀ

LDA pools within-class scatter and divides by \(N\) for the Gaussian maximum-likelihood estimate:

Σ̂ = (1/N) ∑k=1K ∑i:yᵢ=k (xᵢ−μ̂k)(xᵢ−μ̂k)ᵀ

Some software uses a degrees-of-freedom-adjusted covariance estimate instead, so check the convention.

Nearest centroid connection

With equal class priors and shared isotropic covariance \(\Sigma=\sigma^2I\), maximizing the Gaussian class score is equivalent to minimizing squared Euclidean distance to the class mean. With general covariance, the relevant distance is Mahalanobis distance; priors can also shift the boundary.
