Level 1 · High-school intuition

What does an SVM do?

A support vector machine (SVM) separates classes by choosing a decision boundary. In two dimensions, the boundary is a line; in higher dimensions, it is a hyperplane.

Many lines might separate the training examples. A linear SVM chooses the one with the largest margin: the widest possible buffer between the boundary and the closest examples from each class.

Core idea: the closest training points are the support vectors. They anchor the margin and help determine the boundary.

Schematic: center line is the decision boundary; outer lines mark the margin.

Decision function

f(x) = wᵀx + b   ;   predict sign(f(x))

The boundary is \(f(x)=0\). The canonical margin boundaries are \(f(x)=+1\) and \(f(x)=-1\), giving margin width \(2/‖w‖\).

Why maximize the margin?

Small margin

A small change in data can change the boundary substantially; there is little buffer between classes.

Large margin

The boundary leaves more room around nearby examples, which can improve generalization—but does not guarantee it.

Level 2 · Explore the trade-off

Soft margins: what if classes overlap?

Soft-margin SVMs allow points inside the margin or even on the wrong side. Slack variables \(\xi_i\) measure violations; \(C\) controls how costly they are.

minimize: ½‖w‖² + C Σᵢ ξᵢ
subject to: yᵢ(wᵀxᵢ+b) ≥ 1−ξᵢ,   ξᵢ ≥ 0

Balanced penalty: violations matter, but the model still values a wider margin.

The graphic is conceptual, not the output of a trained SVM.

Small C

Violations are relatively cheap. The optimizer may prefer a wider margin even if more points violate it.

Large C

Violations are expensive. The model tries harder to classify training points correctly, possibly becoming more sensitive to outliers.

Nuance: C is not simply “accuracy.” Its best value depends on the data, feature scaling, kernel, and validation.
Level 3 · College-level mathematics

From primal to dual

For a hard-margin linear SVM, minimize the weight norm while requiring each labeled point to be on the correct side of the margin:

min₍w,b₎ ½‖w‖²
subject to yᵢ(wᵀxᵢ+b) ≥ 1

Introducing Lagrange multipliers \(\alpha_i≥0\) and optimizing the Lagrangian over \(w,b\) gives:

w = Σᵢ αᵢ yᵢ xᵢ
Σᵢ αᵢ yᵢ = 0

Substitution produces the dual problem:

maximize₍α₎ Σᵢ αᵢ − ½ ΣᵢΣⱼ αᵢαⱼ yᵢyⱼ xᵢᵀxⱼ
subject to αᵢ ≥ 0,   Σᵢ αᵢyᵢ = 0

Why the dual matters: training examples appear through pairwise inner products \(x_i^\top x_j\). Replace those with kernels and the same optimization can represent nonlinear boundaries.

Support vectors and α

Points safely outside the margin have \(\alpha_i=0\) under the KKT conditions. Support vectors have nonzero multipliers and contribute to the boundary. In a soft-margin SVM, \(0≤\alpha_i≤C\).

Prediction in dual form

f(x) = Σᵢ αᵢ yᵢ (xᵢᵀx) + b

The prediction is expressed using training examples and inner products, which sets up the kernel trick.

★ Focus section · 17.3.4

The kernel trick: nonlinear boundaries without explicit features

Some datasets cannot be separated by a straight line in their original feature space. Imagine mapping each input \(x\) into a richer feature representation \(\phi(x)\), where a linear separator might work.

φ : x ↦ φ(x)
linear score in feature space: wᵀφ(x)+b

Explicitly constructing \(\phi(x)\) can be expensive or even infinite-dimensional. But the SVM dual only needs dot products between mapped examples. A kernel computes these directly:

k(x,z) = φ(x)ᵀφ(z)

The trick: replace every dot product \(x_i^\top x_j\) in the dual problem with \(k(x_i,x_j)\). For prediction, replace \(x_i^\top x\) with \(k(x_i,x)\). The algorithm behaves as if it used \(\phi\), without explicitly building those feature vectors.

Interactive intuition: switch kernels

These points form a ring-like pattern. A straight line cannot isolate the inner class, but a curved boundary can. Switch between kernel types to compare their conceptual behavior.

Linear kernel: the separator stays a straight line in the original input space.

Illustrative sketch, not a numerical SVM fit. Actual boundaries depend on data, C, and kernel parameters.

Three common kernels

Linear

k(x,z)=xᵀz

A linear boundary in the original features; often useful in high-dimensional settings.

Polynomial

k(x,z)=(xᵀz+c)ᵈ

Represents feature interactions up to a degree controlled by \(d\), given suitable parameter choices.

RBF / Gaussian

k(x,z)=exp(−‖x−z‖²/(2ℓ²))

Similarity fades with distance. It can form flexible nonlinear boundaries; length-scale controls the rate of fading.

Valid kernel

Its Gram matrix \(K_{ij}=k(x_i,x_j)\) must be positive semidefinite for every finite set of inputs. This makes it a valid inner-product-like similarity.

Kernel trick in four steps

Start with the dual: it depends on pairwise dot products between training examples.

Imagine a feature map: transform inputs into a representation where a linear separator can solve a nonlinear problem.

Compute similarities directly: use \(k(x,z)=\phi(x)^\top\phi(z)\), without explicitly constructing the features.

Predict by similarity: \(f(x)=\sum_i\alpha_i y_i k(x_i,x)+b\). Only support vectors with nonzero \(\alpha_i\) contribute.

Do not confuse: \(\phi\) is the conceptual feature transformation; \(k\) computes the inner product in that feature space. The trick is that the SVM needs the kernel values, not explicit transformed vectors.
