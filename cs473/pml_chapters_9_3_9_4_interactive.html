Naive Bayes & Generative vs. Discriminative Models

Chapters 9.3–9.4 · Learn the intuition first, then build a model, then connect the equations to statistical learning.

How to use this guide: Start at Level 1, experiment with the controls, then move upward. This is an original learning aid for the topics—not a reproduction of the textbook.

Level 1 — Learn the idea

Imagine an email arrives. Is it spam or not spam? You notice clues: the words “prize,” “meeting,” or “free.” A classifier combines clues and estimates which category is more likely.

Naive Bayes

It asks: “If this email were spam, how likely would these clues be? What if it were not spam?” It combines the clue probabilities with how common each category is.

“Naive” means it treats clues as conditionally independent once the class is known. That is a simplifying assumption—not a claim that words are truly unrelated.

Generative model

Learn a story for each class: what spam emails tend to look like, and what normal emails tend to look like. Then use the story to classify a new email.

Discriminative model

Learn the boundary or probability that separates the classes directly. Rather than modeling how each class generates the email, focus on predicting the label from the clues.

A useful mental picture

Generative

Class → features

“What kinds of clues would a spam email produce?”

P(features, class)
Discriminative

Features → class

“Given these clues, how likely is spam?”

P(class | features)

Model fitting and smoothing

Naive Bayes learns probabilities from labeled examples. If a word never appears in a class in your training sample, its estimated probability may become zero. A single zero can wipe out the entire product score. Laplace smoothing prevents this by adding a small pseudo-count.

Level 3 — College-level formulation

Naive Bayes factorization

Let the feature vector be \(x=(x_1,\ldots,x_D)\) and class be \(y\in\{1,\ldots,K\}\). Bayes’ rule gives

P(y | x) = P(y) P(x | y) / P(x)

The naive conditional-independence assumption factorizes the class-conditional likelihood:

P(x | y) ≈ ∏j=1D P(xj | y)

For classification, the denominator \(P(x)\) is the same for every candidate class, so the predicted class can be found by maximizing the unnormalized score:

ŷ = argmaxy P(y) ∏j=1D P(xj | y)

Products of many small probabilities can underflow numerically. Taking logs preserves the maximizing class and turns products into sums:

ŷ = argmaxy [ log P(y) + Σj=1D log P(xj | y) ]
Important: Conditional independence is assumed given the class. Features can still be correlated overall. For example, “free” and “prize” may co-occur often in spam; naive Bayes may effectively count correlated evidence more than once.

QuestionGenerativeDiscriminative
TargetJoint distribution \(P(x,y)\), often via \(P(y)P(x|y)\)Conditional distribution \(P(y|x)\) or a decision boundary
PredictionUse Bayes’ rule to infer \(y\)Predict \(y\) directly from \(x\)
ExampleNaive Bayes; Gaussian discriminant analysisLogistic regression; many neural classifiers
Potential strengthsCan work well with limited data; can model feature distribution; can sometimes handle missing features naturallyOften focuses model capacity on the classification task; can outperform when enough labeled data is available and assumptions are appropriate
Potential weaknessesWrong assumptions about \(P(x|y)\) can hurt predictions even if class boundary is what mattersDoes not by itself specify how features are generated; missing features may require additional handling

These are tendencies, not guarantees. Performance depends on the data, model assumptions, sample size, and evaluation goal.

Why Naive Bayes can resemble logistic regression

For binary classification, take the log posterior odds:

log [P(y=1 | x) / P(y=0 | x)] = log [P(y=1)/P(y=0)] + Σj log [P(xj|y=1) / P(xj|y=0)]

For suitable feature distributions (such as Bernoulli features), each feature contributes an additive term. This can produce a linear function of the features in log-odds space, like logistic regression. The models are still trained differently: naive Bayes estimates class-conditional feature distributions; logistic regression directly optimizes a conditional prediction objective.

Missing features

If feature \(x_j\) is genuinely unobserved, a generative model can often marginalize it out:

P(xobserved | y) = ∫ P(xobserved, xmissing | y) dxmissing

Under naive Bayes, if the missing feature is separate in the factorization, its likelihood factor can simply be omitted from the product. This is not equivalent to treating a missing value as zero. Missingness may itself carry information, and some feature models require more careful marginalization.
