Method explorer

Self-training: a model trained on labeled examples predicts targets for unlabeled examples. High-confidence predictions are treated as temporary labels and added to training.

ŷᵤ = argmaxᵧ pθ(y | xᵤ), if maxᵧ pθ(y | xᵤ) ≥ τ
ℒtotal = ℒsupervised + λ · ℒpseudo

Increasing τ generally improves the reliability of accepted guesses but reduces coverage. A high-confidence error can still reinforce itself.

Graph-based label propagation: each example is a node; nearby examples are connected by weighted edges. Known labels diffuse through the graph, based on the idea that nearby points tend to share a label.

Wᵢⱼ = exp(−‖xᵢ − xⱼ‖² / 2σ²) for neighbor edges
F ← α S F + (1 − α)Y

The k control changes graph connectivity. Small k can fragment the graph; large k can connect different classes and spread labels across a true boundary. This demo uses simplified local neighbor voting.

Consistency regularization: predictions should remain similar when an input is changed by a label-preserving perturbation or augmentation. Unlabeled data constrains the model without supplying a target class.

ℒ = ℒsup + λu · Eₓᵤ,ξ,ξ′ [ d(fθ(ξ(xᵤ)), fθ(ξ′(xᵤ))) ]

ξ and ξ′ are stochastic augmentations; d measures prediction disagreement. The demo approximates smoothness by averaging predictions around nearby unlabeled examples; it is not a full Π-model, Mean Teacher, or FixMatch implementation.

Cluster assumption: points in the same high-density cluster tend to share a class.

Low-density separation: a useful decision boundary should pass through regions with few observations, not cut through dense clusters.

Manifold assumption: high-dimensional examples may lie near a lower-dimensional structure, and labels vary smoothly along it. These are inductive assumptions, not universal laws.

Mathematical formulation

Labeled set: 𝒟L = {(xᵢ, yᵢ)}ᵢ₌₁ᴸ
Unlabeled set: 𝒟U = {xⱼ}ⱼ₌₁ᵁ

Generic semi-supervised objective:
minθ ℒL(θ; 𝒟L) + λu 𝓡U(θ; 𝒟U)

Supervised loss: ℒL = −Σᵢ log pθ(yᵢ | xᵢ)
Unlabeled regularizer 𝓡U uses p(x), neighborhood structure, or prediction consistency.

The unlabeled set provides information about the input distribution p(x), not directly observed target values y. The algorithm must assume some relationship between the structure of p(x) and the target conditional p(y|x).

Why are pseudo-labels not the same as real labels?

A pseudo-label is a model-generated estimate, not a verified annotation. Confidence can be miscalibrated, especially under distribution shift or when the initial labeled sample is unrepresentative. Thresholding and weighting help manage this risk but cannot remove it entirely.

How is this different from unsupervised and self-supervised learning?

Supervised learning uses labeled pairs. Unsupervised learning finds structure without target labels. Semi-supervised learning combines a small labeled set and unlabeled examples for the same prediction task. Self-supervised learning creates training targets from the data itself, often for representation pretraining.
