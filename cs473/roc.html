The big picture

Chapter 5 asks a decision-theory question: given what we believe about the world, what action should we take? Bayesian decision theory combines a posterior belief with a loss function to choose an action with minimum posterior expected loss.

risk(a | x) = E[ loss(H, a) | x ]

The optimal policy chooses the action with the smallest posterior expected loss. In classification, the actions are usually class labels.

5.1.1 Basics

State of nature H: what is actually true.

Action a: what the decision maker does.

Loss ℓ(H,a): cost of taking action a when H is true.

Risk: expected loss after using the posterior.

5.1.2 Classification

For binary classification, the true class is 0 or 1 and the prediction is 0 or 1.

With zero-one loss, an error costs 1 and a correct prediction costs 0. The minimum-risk decision is therefore the most probable class (MAP).

ŷ = argmaxᵧ p(y | x)

Cost-sensitive classification

Errors do not always cost the same. If a false negative is much more costly than a false positive, the decision threshold can move so that the classifier predicts positive more readily.

Key idea: changing the threshold changes the confusion matrix—and therefore changes TPR and FPR.

Why ROC curves exist

A probabilistic classifier can give a score such as p(y=1|x)=0.83. We still need a rule for converting that score into 0/1. Choose a threshold t:

predict 1 if score ≥ t
predict 0 if score < t

Instead of committing to one threshold, an ROC curve asks: “What happens to our true-positive rate and false-positive rate as we move the threshold?”

ROC = TPR plotted against FPR as the classification threshold varies.
Horizontal axis: FPR. Vertical axis: TPR.

The pairs you should memorize

TPR + FNR = 1
FPR + TNR = 1

TPR = 1 − FNR
FPR = 1 − TNR

Memory trick: TPR/FNR are about the positive truth row. TNR/FPR are about the negative truth row.

Don't confuse these with precision

TPR / Recall = TP / (TP + FN)
Precision / PPV = TP / (TP + FP)

TPR asks: “How many real positives did I find?”
Precision asks: “How many of my positive predictions were actually positive?”

AUC and EER

AUC is the area under the ROC curve. It compresses the whole threshold sweep into one scalar. An AUC of 1 represents perfect separation; an AUC near 0.5 corresponds to chance-like ranking.

EER (equal error rate) is the point where FPR = FNR. Since FNR = 1 − TPR, this means the ROC point satisfies:

FPR = 1 − TPR

Geometrically, it is where the ROC curve meets the diagonal running from (0,1) to (1,0).
