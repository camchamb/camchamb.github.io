Why use an ensemble?

A decision tree makes predictions by repeatedly splitting the feature space. Trees are flexible and interpretable, but a single deep tree can be unstable: small changes in the training data may produce a different tree.

An ensemble combines multiple learners. Two major strategies are:

Bagging / random forests

Train many trees using randomized datasets and/or feature subsets, then average their predictions. Trees are trained largely independently.

Boosting

Train learners sequentially. Each new learner is chosen to improve the current ensemble, often by focusing on residuals, gradients, or difficult examples.

Big distinction: random forests mainly reduce variance by averaging diverse trees; boosting builds a strong predictor by adding weak learners that correct what the current model misses.

One model vs an ensemble

Suppose several trees each make somewhat noisy predictions. Averaging can cancel some of their individual errors—especially when their errors are not perfectly correlated. Boosting instead makes each next learner conditional on the current ensemble's mistakes.

Section 18.4 · Random forests

How a random forest works

Bootstrap sample: for each tree, draw a training set by sampling examples with replacement from the original dataset.
Grow a tree: fit a decision tree to that bootstrap sample.
Random feature subset: at each split, consider only a randomly selected subset of features rather than all features.
Aggregate: classification usually uses majority vote (or averaged class probabilities); regression averages tree predictions.
Two sources of randomness—bootstrap rows and candidate features—make trees less correlated. Averaging less-correlated trees can substantially reduce variance.

Why feature randomness matters

If one feature is extremely predictive, ordinary bagged trees may all choose it near the root and look similar. Restricting candidate features encourages different trees to explore different patterns.

Interactive: averaging reduces variance

Var(average) / Var(single tree) = ρ + (1−ρ)/B

This formula assumes equal tree variance and equal pairwise error correlation. It illustrates the benefit and limit of averaging; it is not a full random-forest performance model.

Out-of-bag (OOB) evaluation

Because each tree is trained on a bootstrap sample, some training examples are left out of that tree's sample. Those are its out-of-bag examples. For each training case, aggregate predictions from trees for which that case was OOB. This gives an internal estimate of generalization error without requiring a separate validation fold for every tree.

Strengths and limitations

Strengths

  • Often strong performance with little feature engineering.
  • Captures nonlinearities and interactions.
  • Less sensitive than a single tree to training-set variation.
  • OOB error and feature-importance estimates are available.

Limitations

  • Less interpretable than one small tree.
  • Large forests can use substantial memory and inference time.
  • Impurity-based feature importance can favor high-cardinality features.
  • Extrapolation in regression is often limited by tree leaf predictions.
Section 18.5.1 · Forward stagewise additive modeling

Boosting builds an additive model one learner at a time

Represent the prediction function as a sum of weak learners:

F_M(x) = Σₘ₌₁ᴹ αₘ hₘ(x)

At each stage, add a new learner to improve the objective. A generic stagewise step is:

Fₘ(x) = Fₘ₋₁(x) + αₘ hₘ(x)

The new learner \(h_m\) and weight \(\alpha_m\) are selected to reduce the chosen loss, while earlier learners are held fixed. This is a greedy optimization of an additive model—not necessarily a globally optimal joint fit.

Think of it like editing a draft: keep the current prediction, inspect what is still wrong, and add a small correction. Repeat.

Loss functions define what “wrong” means

  • Squared error emphasizes large residuals and leads to least-squares boosting.
  • Exponential loss leads to AdaBoost for binary classification.
  • Binomial deviance / logistic loss leads to LogitBoost-style probability modeling.
Section 18.5.2 · Quadratic loss and least-squares boosting

Fit each new learner to the residuals

For regression, use squared-error loss:

L(y,F(x)) = ½(y−F(x))²

The residual at stage m is:

rᵢₘ = yᵢ − Fₘ₋₁(xᵢ)

Fit a new regression tree \(h_m(x)\) to these residuals. Then choose a step size \(\alpha_m\) (often by line search) and update:

Fₘ(x) = Fₘ₋₁(x) + αₘ hₘ(x)

Intuition: the next tree predicts what the current ensemble is still getting wrong. It does not rebuild the original target from scratch.

Section 18.5.3 · Exponential loss and AdaBoost

AdaBoost: focus attention on mistakes

AdaBoost combines weak binary classifiers. Encode labels as \(y_i\in\{-1,+1\}\) and weak predictions as \(h_m(x_i)\in\{-1,+1\}\). It minimizes exponential loss:

L = Σᵢ exp(−yᵢ F(xᵢ))

At each round, fit a weak learner using the current example weights. Examples misclassified by the learner receive increased relative weight; correctly classified examples receive decreased relative weight.

Core AdaBoost equations

εₘ = Σᵢ wᵢ 𝟙[yᵢ ≠ hₘ(xᵢ)] / Σᵢ wᵢ
αₘ = ½ log((1−εₘ)/εₘ)
wᵢ ← wᵢ exp(−αₘ yᵢ hₘ(xᵢ))

Weights are then normalized to sum to one. The final classifier is:

H(x) = sign(Σₘ αₘ hₘ(x))

Meaning of α: a weak learner with smaller weighted error gets a larger vote. If ε is below 0.5, its vote is positive; an error of 0.5 gives no useful edge over random guessing.

Interactive: weak learner error → vote weight

Why reweight?

After several rounds, examples that remain difficult can become influential in later rounds. Each weak learner focuses on a different weighted view of the training set. AdaBoost can produce a strong classifier from learners that are only moderately better than chance, provided the assumptions and training process behave well.

Caution: AdaBoost can be sensitive to label noise and outliers because persistently misclassified examples may accumulate large weights.
Section 18.5.4 · LogitBoost

LogitBoost: boosting probabilities with logistic loss

LogitBoost builds an additive model for classification by optimizing binomial log-likelihood (equivalently, logistic deviance). Unlike AdaBoost's exponential loss and reweighted classification error, LogitBoost is connected to fitting a logistic model through a stagewise procedure.

For binary labels \(y_i\in\{0,1\}\), represent the probability using a score \(F(x)\):

p(x) = P(y=1|x) = 1 / (1 + exp(−F(x)))

The negative log-likelihood for one example is:

L(y,F) = −y log p − (1−y)log(1−p)

LogitBoost uses a Newton-style update. At each stage it constructs working responses and weights from the current probabilities, fits a regression learner to the working response using those weights, and updates the additive score.

Working response and weights

pᵢ = 1/(1+exp(−F(xᵢ)))
wᵢ = pᵢ(1−pᵢ)
zᵢ = (yᵢ−pᵢ) / [pᵢ(1−pᵢ)]

The weighted regression fit to \(z_i\) approximates a Newton step for the logistic objective. Implementations may include stabilizing constants, clipping, or learning-rate adjustments to avoid extreme values.

Interpretation: \(y_i-p_i\) is the probability residual. The denominator \(p_i(1-p_i)\) is the Bernoulli variance. The working response rescales the residual into a Newton-style correction; the weight is largest near \(p_i=0.5\).

Interactive: logistic probability and curvature weight

AdaBoost vs LogitBoost

AdaBoost

  • Exponential loss.
  • Uses example reweighting based on mistakes.
  • Final classifier is a weighted vote of weak classifiers.

LogitBoost

  • Binomial logistic loss / deviance.
  • Uses working responses and weights from Newton-style optimization.
  • Naturally models class probabilities through a logistic link.
Both are boosting methods: they add learners stage by stage. The major difference here is the objective and the way each stage is computed.
