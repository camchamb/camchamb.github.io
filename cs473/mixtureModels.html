1. Mixture models

A mixture model makes a more complex probability distribution by combining simpler component distributions.

p(y|θ) = Σₖ πₖ pₖ(y),   πₖ ≥ 0,   Σₖπₖ=1

Component

A simpler distribution used as one piece of the mixture.

Weight πₖ

The probability of selecting component k before observing y.

Latent z

A hidden categorical variable telling us which component generated y.

Marginalization

Because z is hidden, sum over possible z values to obtain p(y).

2. Generative story

  1. Choose z ~ Categorical(π).
  2. Generate y from component p(y|z=k).
  3. Since z is unobserved, p(y)=Σₖp(z=k)p(y|z=k).
Key idea: an observation is generated by one selected component, not by averaging several components for that observation.

3. GMMs and BMMs

Gaussian mixture model: p(y)=Σₖπₖ N(y|μₖ,Σₖ). GMMs are useful for real-valued data and clustering.

Bernoulli mixture model: each component is a product of Bernoulli distributions, useful for binary-valued data.

For a GMM, the hidden component assignment can be inferred with a posterior responsibility:

rₙₖ = p(zₙ=k | yₙ, θ)

4. Bias–variance tradeoff

For an estimator θ̂ applied to repeated datasets:

Bias(θ̂)=E[θ̂]−θ*     Var(θ̂)=E[(θ̂−Eθ̂)²]
MSE = Variance + Bias²

Bias measures systematic error. Variance measures sensitivity to the particular dataset. Under squared error, a little bias can be worthwhile if it reduces variance enough.

Scope: this exact decomposition is for squared-error estimation. Murphy notes that it does not directly become the same additive decomposition for 0–1 classification loss.
