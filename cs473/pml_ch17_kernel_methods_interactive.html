Level 1 · High-school intuition

What is a kernel?

Imagine you want to predict a house price. Instead of deciding only whether two houses are close in raw feature space, you need a way to measure how similar they are for the pattern you care about.

A kernel is a function \(k(x,x')\) that measures similarity between inputs. In many kernel methods, it acts as if the inputs were mapped into a richer feature space, where simple relationships can represent complicated patterns—without explicitly building that mapping.

Core idea: a kernel is a similarity rule; a Gaussian process (GP) uses that rule to describe which functions are plausible and how predictions at different inputs relate.

Analogy: a flexible rubber ruler

A linear kernel says similarity depends on alignment with a straight-line pattern. An RBF (Gaussian) kernel says nearby inputs are strongly related, while distant inputs become less related. Its length-scale controls how quickly similarity fades.

Short length-scale

Only very nearby points influence each other strongly. The model can change rapidly and fit wiggly patterns.

Long length-scale

Even points farther apart remain related. Predictions tend to vary more smoothly.

What is a Gaussian process?

A GP is a probability distribution over functions. Instead of choosing one curve immediately, it describes many possible curves and how plausible each is before and after seeing data.

1
Prior: choose a mean function \(m(x)\) and kernel \(k(x,x')\). These define the broad shapes and relationships expected before observing data.
2
Observe examples: see input-output pairs, such as measured temperature at several times.
3
Condition on data: update the distribution over functions. Curves inconsistent with observations become less plausible.
4
Predict: get both a predictive mean and uncertainty. Uncertainty usually grows farther from observed inputs.

f(x) ~ GP(m(x), k(x,x'))

The notation says that any finite collection of function values has a joint Gaussian distribution. The kernel gives their covariance.

Why mention noisy observations?

Real measurements are rarely exact. A thermometer may read 21.4°C when the underlying temperature is 21.0°C. A noisy GP separates the smooth latent function \(f(x)\) from measurement noise:

y = f(x) + ε,   ε ~ N(0, σ²)

The model should learn the underlying trend without trying to pass exactly through every noisy measurement.

Level 3 · College-level math

Mercer kernels: the important properties

A symmetric positive-semidefinite kernel assigns a Gram matrix \(K\) to any finite set of inputs \(x_1,\dots,x_n\), where \(K_{ij}=k(x_i,x_j)\). Positive semidefinite means:

aᵀ K a ≥ 0 for every vector a

This condition matters because a covariance matrix must be positive semidefinite. It ensures the kernel can serve as a valid covariance function for a GP (under the usual domain/regularity assumptions).

Common examples

  • Linear: \(k(x,x')=x^\top x'\). Captures linear relationships in the original feature space.
  • Polynomial: \(k(x,x')=(x^\top x'+c)^d\), with suitable parameter choices. Captures interactions up to a chosen degree.
  • RBF / squared exponential: \(k(x,x')=\sigma_f^2\exp[-\|x-x'\|^2/(2\ell^2)]\). Encodes smoothness, with signal scale \(\sigma_f^2\) and length-scale \(\ell\).
Mercer intuition: a valid kernel behaves like an inner product in some feature space, \(k(x,x')=\phi(x)^\top\phi(x')\), possibly one that is very high- or infinite-dimensional. You usually calculate \(k\) directly rather than construct \(\phi\).

GP regression with noisy observations

Assume a zero-mean GP prior and training data \(X=(x_1,\ldots,x_n)\), \(y=(y_1,\ldots,y_n)^\top\):

f ~ GP(0, k),   y = f(X) + ε,   ε ~ N(0, σ²I)

Define \(K_{XX}\) by \([K_{XX}]_{ij}=k(x_i,x_j)\). Noise adds \(\sigma^2 I\) to the covariance of observed targets:

y ~ N(0, Kₓₓ + σ²I)

For test inputs \(X_*\), let \(K_{*X}\) be test-to-training covariance, \(K_{X*}=K_{*X}^\top\), and \(K_{**}\) be test-to-test covariance. The posterior predictive distribution of latent function values is Gaussian:

f* | X,y,X* ~ N( μ*, Σ* )

μ* = K*X (KXX + σ²I)⁻¹ y

Σ* = K** − K*X (KXX + σ²I)⁻¹ KX*

The mean is a data-weighted combination determined by covariance. The covariance subtracts uncertainty explained by the observations. For predicting a new noisy target \(y_*\), add observation noise to the latent predictive covariance: \(\Sigma_{y_*}=\Sigma_*+\sigma^2I\).

Derivation: why does the noise appear on the diagonal?

1
Latent training values have covariance \(K_{XX}\).
2
Independent observation noise has covariance \(\sigma^2I\): each observation gets variance \(\sigma^2\), and different noise terms have zero covariance.
3
Independent covariances add, so \(\operatorname{Cov}(y)=K_{XX}+\sigma^2I\).
4
Conditioning a joint Gaussian gives the predictive mean and covariance above. In practice, solve linear systems using a Cholesky factorization rather than explicitly forming a matrix inverse.
Common distinction: \(\sigma^2\) is measurement-noise variance, while \(\sigma_f^2\) is the latent function's signal variance. They describe different sources of variation.

One-minute summary

  • A kernel is a similarity function whose Gram matrices are positive semidefinite.
  • A GP is a distribution over functions; the kernel specifies covariance between function values.
  • GP regression returns a predictive mean and uncertainty.
  • With noisy targets, use \(K_{XX}+\sigma^2I\); add test noise when predicting a new observed target rather than the latent function.
