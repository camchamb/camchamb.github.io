03 · EIGENDECOMPOSEFind principal axesEigenvectors give directions; eigenvalues quantify variance.
04 · PROJECTReduce dimensionsKeep k components, transform and optionally reconstruct.

Concept explorer

Variance maximization: PCA rotates the coordinate system to align with directions of maximum variation. PC1 is the direction along which the projected samples have greatest variance. PC2 is perpendicular to PC1 and maximizes the remaining variance.

For an elongated cloud, retaining PC1 may preserve much of the variability. For a circular cloud, no direction dominates; eigenvectors may be sensitive to small sample changes.

Center: Xc = X − μ
Optional standardization: Zij = (Xij − μj) / σj
Covariance: C = (1 / (n − 1)) Xcᵀ Xc
Eigenproblem: C vᵢ = λᵢ vᵢ
Order: λ₁ ≥ λ₂ ≥ ⋯ ≥ λd
Projection: Z = Xc Vₖ
Reconstruction: X̂ = Z Vₖᵀ + μ
Explained ratio: rᵢ = λᵢ / Σⱼ λⱼ

Covariance PCA: works on centered features and is sensitive to feature units. A variable measured in thousands can dominate one measured in decimals.

Correlation PCA: standardizes variables first. Different scales become comparable, but low-variance features may receive as much initial influence as high-variance ones.

PCA captures linear directions and can miss nonlinear structure. Components are ranked by variance, not predictive value. PCA can be sensitive to outliers, discard useful low-variance signal, and does not automatically make features independent. It is not a clustering method and does not use class labels.

Why does PCA minimize reconstruction error?

For centered data and an orthonormal PCA basis, keeping the top k components gives the optimal rank-k linear reconstruction in squared-error terms. The total loss is related to the sum of discarded eigenvalues, with normalization depending on the convention.

Should I choose components by explained variance?

Explained variance is a useful compression criterion, but not a guarantee of better prediction. Select k using validation performance or domain requirements when PCA is part of a predictive pipeline.
